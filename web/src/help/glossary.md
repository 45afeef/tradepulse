# Glossary

A short list of the words used in TradePulse.

| Word | Meaning |
|---|---|
| **Source** | Where items come from: a news feed, a web page, an account, or a system that sends items in. |
| **Topic** | A tag on an item, such as markets or outages. You can follow topics. |
| **Keyword** | A word or phrase matched in an item's title or text. |
| **Follow** | Tell TradePulse you want items from a source, topic or keyword in your feed. |
| **Feed** | Your live, newest-first list of everything you follow. |
| **View** | A saved filter over your feed, shown as a tab. |
| **Alert** | A rule that interrupts you when a matching item arrives. |
| **Template** | A ready-made alert you only need to fill in. |
| **Preview** | A check of how often an alert would have fired recently. |
| **Cooldown** | The minimum time between two alerts from the same rule. |
| **Importance** | How significant you rate an alert: info, notable or high. |
| **Channel** | Where alerts are delivered: the app itself, or a webhook. |
| **Webhook** | Your own web address that receives alerts automatically. |
| **Signature** | A code on each webhook delivery that proves it came from TradePulse. |
| **Operator** | The person who runs your TradePulse workspace and can add sources and invite members. |
